# WarioGame

A small game made in Godot 
There are two minigames to beat, and you start with five hearts
If you loose you loose a heart! IF YOU LOOSE ALL OF EM you loose the game 🫨

<img width="1134" height="629" alt="image" src="https://github.com/user-attachments/assets/72e8f08b-f58a-4f50-a6b0-0d43810ac7fb" />


## Minigames

### Collect the coins
Move around the platforms and collect all three coins within 10 seconds. There are moving platforms too so watch your jumps.

- Left/right arrow keys to move
- Space to jump

<img width="1134" height="615" alt="image" src="https://github.com/user-attachments/assets/6271803a-3c28-4a94-8577-0a513594e8c3" />

### Hit the targets
Click all four moving targets within 7 seconds.

- Left mouse button to click

<img width="1152" height="642" alt="image" src="https://github.com/user-attachments/assets/e0988d29-41e8-4097-a697-7ca8a93ad875" />


Beat both minigames to win. Lose all five hearts and you'll have to start again.

## Running the project

Download or clone this repository
import `project.godot` into Godot 4.7 and press F5.
